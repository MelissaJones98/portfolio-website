# Portfolio Website

My personal portfolio website, introducing who I am as a junior full-stack developer and bringing my projects and certificates together in one place.

> **Status: rebuild in progress.** The content is in place, but styling and interactivity are still to come, and the site isn't deployed yet.

## What's on the Site

It's a single page, with these sections:

- **Header:** navigation links, my photo, name and job title
- **About Me:** a short bio covering how I work and my creative hobbies
- **Projects:** 14 project cards, each with a description, the technologies used and a link to its GitHub repository (many also list features)
- **Certificates and Qualifications:** certificates from Codecademy, IT Career Switch and Zenva, shown with their completion dates
- **Contact Me:** a form with name, email and message fields
- **Footer:** copyright notice and a link to my GitHub profile

## Technologies

- HTML
- CSS
- JavaScript (`script.js` is linked but doesn't contain any code yet)

There are no frameworks, dependencies or build steps.

## Running Locally

1. Clone the repository:

   ```bash
   git clone git@github.com:MelissaJones98/portfolio-website.git
   ```

2. Open `index.html` in your browser.
